## ルール

- 自分を含め2〜4人で同じ10問。各問の開始前に3秒、回答は150秒まで。ホストが2人以上そろった時点で開始できます。
- 棄権していない全員の回答後、または制限時間後に正答を5秒間表示します。全問の解説は対戦終了後にも確認できます。
- 正解数が多い人の勝ち。同数なら合計回答時間が短い人の勝ち。両方同じなら引き分けです。
- 途中退出は棄権となり、残りの参加者で続行します。最後の1人が勝利します。通信切断だけでは棄権にならず、同じアカウントで対戦へ戻ると復帰できます。待機ルームは30分、開始後は2時間で期限切れになります。
- 結果は順位順に表示します。同じ正解数・回答時間なら同順位（1位・1位・3位・4位）。棄権者は順位なしで末尾に表示します。
