# フレンド対戦の公開設定

画面と対戦処理は実装済みです。2026年9月9日に公開用 Supabase（`mjkecekrkjzfkqhbuizq`）へ `battle-install.sql` を反映しました。管理画面で全1,125問と6つの対戦用関数を確認し、公開APIが未ログイン要求を `AUTH_REQUIRED` で拒否することも確認済みです。2画面の10問対戦はローカル環境で検証済みです。外部に配信しているサイトのファイル更新は、この設定反映には含まれません。

1. Supabase 管理画面で、既存の RE:CARE プロジェクト（`mjkecekrkjzfkqhbuizq`）を開きます。
2. SQL Editor に `setup/battle-install.sql` の全文を貼り付け、実行します。既存のアカウント設定が必要です。
3. サイトに変更済みファイルを反映し、別のアカウント・端末でログインします。「友達と対戦する」から、一方がルームを作り、もう一方が6桁の番号で参加してください。

設定ファイルは対戦用のテーブル・処理・全1,125問の採点データをまとめたものです。既存の学習記録を削除しません。再実行できます。管理用の秘密鍵をサイトへ追加する必要はありません。

## ルール

- 2人で同じ10問。各問の開始前に5秒、回答は120秒まで。
- 2人の回答後、または制限時間後に正答を8秒間表示します。全問の解説は対戦終了後にも確認できます。
- 正解数が多い人の勝ち。同数なら合計回答時間が短い人の勝ち。両方同じなら引き分けです。
- 途中退出は負け。通信切断時は同じアカウントで対戦へ戻ると復帰できます。待機ルームは30分、開始後は2時間で期限切れになります。
