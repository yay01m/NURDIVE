# RE:CARE オリジナル問題 第1集
国試対策用の独自作成20問。AIによる作成・資料照合。医療専門職の監修なし。

## 第1問｜人体の構造と機能：肺循環

右心室から拍出された血液が、肺でガス交換を行って左心房に戻る経路として正しいのはどれか。

1. 肺静脈 → 肺毛細血管 → 肺動脈
2. 肺動脈 → 肺毛細血管 → 肺静脈
3. 大動脈 → 肺毛細血管 → 大静脈
4. 大静脈 → 肺毛細血管 → 大動脈

**正答：2**

- 選択肢1：肺静脈は肺から左心房へ血液を戻す血管であり、右心室から出る経路ではない。
- 選択肢2：右心室の血液は肺動脈を通って肺へ向かい、ガス交換後に肺静脈を通って左心房に戻る。動脈・静脈の区別は、心臓から出るか戻るかで考える。
- 選択肢3：大動脈から全身の組織を経て大静脈に戻るのは体循環である。肺毛細血管を通る肺循環とは異なる。
- 選択肢4：大静脈は全身から右心房に血液を戻す。右心室から肺へ向かう血管ではない。

## 第2問｜人体の構造と機能：腎性貧血

慢性腎臓病の患者に貧血がみられる。腎機能低下に伴う赤血球産生の減少に直接関係するホルモンはどれか。

1. インスリン
2. 甲状腺刺激ホルモン
3. エリスロポエチン
4. オキシトシン

**正答：3**

- 選択肢1：インスリンは血糖調節に関わる。腎性貧血における赤血球産生低下の直接の説明にはならない。
- 選択肢2：甲状腺刺激ホルモンは甲状腺ホルモンの分泌を促す。腎臓からの造血刺激を担うホルモンではない。
- 選択肢3：腎臓でつくられるエリスロポエチンは骨髄の赤血球産生を促す。腎機能低下による分泌不足は腎性貧血の要因となる。
- 選択肢4：オキシトシンは子宮収縮や射乳に関わる。赤血球産生を促す主な腎由来ホルモンではない。

## 第3問｜人体の構造と機能：インスリン

食後に血糖値が上昇したとき、インスリンの作用として適切なのはどれか。

1. 筋肉や脂肪組織へのブドウ糖の取り込みを促す
2. 尿へのブドウ糖排泄だけで血糖値を下げる
3. 肝臓からのブドウ糖放出を増やす
4. 筋肉でのブドウ糖利用を抑える

**正答：1**

- 選択肢1：インスリンは筋肉や脂肪組織へのブドウ糖の取り込みなどを促し、血糖値を低下させる方向に働く。
- 選択肢2：インスリンの主な血糖低下作用は尿へ糖を捨てることではなく、組織での利用や貯蔵を促すことである。
- 選択肢3：肝臓からのブドウ糖放出の増加は血糖を上げる方向に働く。インスリンはこの放出を抑える。
- 選択肢4：インスリンは筋肉への糖の取り込みや利用を促す。抑えるという説明は逆である。

## 第4問｜基礎看護学：標準予防策

感染症の診断がなく、感染症検査も陰性の患者の採血を行う。標準予防策について適切なのはどれか。

1. 検査が陰性なので適用しない
2. 発熱があるときだけ適用する
3. 感染症が確定した後に開始する
4. 感染症の診断にかかわらず適用する

**正答：4**

- 選択肢1：検査結果だけですべての感染性を否定することはできない。陰性でも標準予防策の対象となる。
- 選択肢2：標準予防策は発熱の有無で適用を決めない。予測される血液・体液への接触に応じて防護する。
- 選択肢3：感染症が未診断の段階も含め、すべての患者に標準予防策を適用する。
- 選択肢4：すべての患者に適用し、手指衛生や、血液への接触が予測される処置での手袋などを実施する。

## 第5問｜基礎看護学：針刺し予防

採血後の使用済み注射針の取り扱いとして最も適切なのはどれか。

1. 手で針を曲げてから捨てる
2. 原則としてリキャップせず、近くの専用容器へ直ちに廃棄する
3. ポケットに入れ、処置終了後にまとめて捨てる
4. 針先に両手でキャップを戻してから運ぶ

**正答：2**

- 選択肢1：手で針を曲げる操作は針刺しの機会を増やす。不要な操作を加えず安全に廃棄する。
- 選択肢2：使用済み針は原則としてリキャップしない。使用場所の近くにある耐貫通性の専用容器へ速やかに廃棄する。
- 選択肢3：使用済み針をポケットに入れると本人や周囲の人が受傷する危険がある。
- 選択肢4：両手でのリキャップは指を針先に近づけるため危険である。原則として行わない。

## 第6問｜基礎看護学：輸液速度の計算

輸液ポンプを用い、輸液500 mLを4時間で投与する指示がある。中断はないものとする。設定する流量はどれか。

1. 100 mL/時
2. 120 mL/時
3. 125 mL/時
4. 250 mL/時

**正答：3**

- 選択肢1：100 mL/時では500 mLの投与に5時間かかり、指示の4時間より長い。
- 選択肢2：120 mL/時では4時間で480 mLとなり、指示された500 mLに達しない。
- 選択肢3：流量は総量÷時間で求める。500 mL÷4時間＝125 mL/時となる。
- 選択肢4：250 mL/時では2時間で500 mLとなり、指示より速い。

## 第7問｜成人看護学：心不全の増悪

慢性心不全で通院する患者が「ここ数日で体重が増え、足首がむくみ、横になると息苦しい」と話した。まず疑う状態として適切なのはどれか。

1. 筋肉量の増加による体重増加
2. 食事制限による栄養不足だけ
3. 運動による一時的な疲労だけ
4. 体液貯留を伴う心不全の増悪

**正答：4**

- 選択肢1：数日間の体重増加に浮腫や臥位での呼吸困難が重なる場合、筋肉量の増加だけでは説明しにくい。
- 選択肢2：栄養状態の評価も必要だが、浮腫と呼吸困難を伴う経過では心不全の増悪を優先して考える。
- 選択肢3：疲労だけと判断すると、体液貯留や呼吸状態の悪化を見逃すおそれがある。
- 選択肢4：体重増加・下肢浮腫・横になると強まる呼吸困難は心不全の増悪を疑う所見である。呼吸状態などを評価し、速やかに医療者へつなぐ。

## 第8問｜成人看護学：低血糖の徴候

インスリン治療中の患者が食事を十分に取れなかった。低血糖を疑う徴候の組合せはどれか。

1. 冷汗・手指のふるえ・動悸
2. 持続する高熱・膿性痰・咽頭痛
3. 黄疸・灰白色便・皮膚のかゆみ
4. 血尿・排尿痛・残尿感

**正答：1**

- 選択肢1：低血糖では発汗、ふるえ、動悸などがみられる。症状だけで確定せず血糖を確認し、意識・嚥下状態に応じた対応につなげる。
- 選択肢2：高熱や膿性痰は感染症などを考える所見であり、低血糖の代表的な徴候の組合せではない。
- 選択肢3：黄疸や灰白色便は胆汁の流れの異常などを考える所見である。
- 選択肢4：血尿や排尿痛は尿路の病変などを考える所見であり、低血糖の典型的な組合せではない。

## 第9問｜成人看護学：脳卒中の初期対応

外来待合室で、患者に突然、片側の口角の下がり、片腕の脱力、ろれつの回りにくさが出現した。看護師の対応として最も適切なのはどれか。

1. 次の予約日まで様子を見るよう説明する
2. 飲水を勧めて落ち着くまで待つ
3. 緊急対応を要請し、発症時刻または最後に普段どおりだった時刻を確認する
4. 症状が消えるまで一人で休ませる

**正答：3**

- 選択肢1：突然の片側の麻痺や言語の異常は脳卒中を疑う。通常の予約日まで待たせない。
- 選択肢2：嚥下機能が障害されている可能性があり、安易な飲水は避ける。緊急評価を優先する。
- 選択肢3：脳卒中を疑い、施設の緊急対応につなぐ。発症時刻や最終健常確認時刻は治療判断に重要である。
- 選択肢4：症状が一時的に改善しても緊急評価が必要である。一人にせず状態を観察する。

## 第10問｜老年看護学：暑熱時の水分摂取

暑い日に自宅で過ごす高齢者から「のどが渇かないので、今日はほとんど飲んでいない」と聞いた。水分制限の指示はなく、嚥下機能は保たれている。適切な助言はどれか。

1. 口渇を感じるまで飲まなくてよい
2. 涼しい環境を整え、定期的に水分を取る
3. 夜間だけに水分摂取をまとめる
4. 飲水の代わりに厚着をして発汗を促す

**正答：2**

- 選択肢1：高齢者では口渇だけを目安にすると摂取不足になることがある。摂取状況も確認する。
- 選択肢2：暑熱を避け、定期的に水分を取る。持病や水分制限がある場合は個別の指示に合わせる。
- 選択肢3：夜間にまとめると日中の水分不足を防ぎにくい。生活に合わせて分けて摂取する。
- 選択肢4：厚着で発汗を促すと熱がこもり、水分も失われる。涼しい環境づくりが必要である。

## 第11問｜老年看護学：転倒予防

夜間にトイレへ行く高齢者の自宅を訪問した。寝室からトイレへの廊下が暗く、電気コードが通路を横切っている。優先する環境調整はどれか。

1. 歩行機能を保つため、コードはそのままにする
2. 移動時間を短くするため、走るよう勧める
3. 足元灯を消してまぶしさを防ぐ
4. 通路のコードを移し、足元を照らす照明を設ける

**正答：4**

- 選択肢1：通路の障害物はつまずきの原因となる。運動の機会をつくることと障害物を残すことは別である。
- 選択肢2：急いだ移動は転倒につながりやすい。安全な動線を整える。
- 選択肢3：暗さは足元の確認を難しくする。まぶしさに配慮しつつ、移動に必要な照明を確保する。
- 選択肢4：障害物を取り除き、夜間の足元が見えるようにすることは転倒予防の基本的な環境調整である。

## 第12問｜老年看護学：認知症の人との会話

認知症のある患者が、更衣の説明を途中で理解できなくなり困っている。看護師の対応として適切なのはどれか。

1. 短い言葉で一つずつ伝え、反応を待つ
2. すべての手順を早口で繰り返す
3. できない理由を問い詰める
4. 本人には話しかけず、家族だけに説明する

**正答：1**

- 選択肢1：一度に伝える情報を少なくし、理解や反応に時間を取る。本人の尊厳を保ちながら、必要に応じて動作も示す。
- 選択肢2：多くの情報を速く伝えると混乱を強めることがある。短く分かりやすい説明にする。
- 選択肢3：問い詰めると不安や負担を増やす。できることに注目し、落ち着いた声で支援する。
- 選択肢4：家族の協力は有用だが、本人を会話から外すのではなく、理解しやすい方法で本人にも説明する。

## 第13問｜小児看護学：乳児の安全な睡眠

健康な生後2か月の乳児の保護者へ、家庭での睡眠環境を説明する。適切なのはどれか。

1. 柔らかい枕で頭を高くする
2. 同じ寝床にぬいぐるみを置く
3. 硬く平らな寝床に、あおむけで寝かせる
4. 寝返り防止用のクッションで両側を囲む

**正答：3**

- 選択肢1：乳児の寝床に柔らかい枕を置くと、顔が埋もれるなどの危険がある。
- 選択肢2：ぬいぐるみなどの柔らかい物は寝床から除く。気道をふさぐ危険を減らす。
- 選択肢3：寝かせるときはあおむけとし、硬く平らな乳児用寝床を使う。周囲に柔らかい物や緩い寝具を置かない。
- 選択肢4：体位を固定するクッションは安全な睡眠のために必要ではなく、顔をふさぐ危険がある。

## 第14問｜小児看護学：経口補水

下痢のある幼児に軽度の脱水がみられる。意識は清明で飲水でき、医師から経口補水液を使用する方針が示された。経口補水液を用いる目的として適切なのはどれか。

1. 下痢を直ちに止める
2. 失われた水分と電解質を補う
3. 腸内の病原体を直接殺す
4. 食事の栄養をすべて置き換える

**正答：2**

- 選択肢1：経口補水液の主目的は脱水への対応であり、下痢を直ちに止める薬ではない。
- 選択肢2：経口補水液は水分と電解質の補給に用いる。飲めなくなる、意識が変化するなどの場合は再評価が必要である。
- 選択肢3：経口補水液は抗菌薬や消毒薬ではなく、病原体を直接殺す目的では使用しない。
- 選択肢4：経口補水液は食事のすべての栄養素を備えた代替食ではない。栄養については状態に応じた方針を確認する。

## 第15問｜母性看護学：妊娠中の警告症状

妊娠32週の妊婦から「強い頭痛が続き、目がかすむ」と電話があった。最も適切な対応はどれか。

1. 危険な症状の可能性を説明し、直ちに産科へ連絡・受診するよう案内する
2. 次回の定期健診まで待つよう伝える
3. 妊娠中には必ず起こるので心配ないと伝える
4. 市販薬の量を増やすよう勧める

**正答：1**

- 選択肢1：持続する強い頭痛や視覚の異常は妊娠高血圧症候群などの重大な状態を疑う警告症状である。速やかな産科での評価につなげる。
- 選択肢2：定期健診まで待たせると緊急性のある状態を見逃すおそれがある。
- 選択肢3：妊娠に伴う正常な変化と決めつけず、症状と緊急性を評価する。
- 選択肢4：自己判断で薬を増量するのではなく、症状の原因を評価するための受診を優先する。

## 第16問｜母性看護学：妊娠中の予防接種

妊娠中の女性に対する麻疹・風疹混合（MR）ワクチンの説明として適切なのはどれか。

1. 不活化ワクチンなので妊娠中も通常どおり接種する
2. 妊娠後期であれば必ず接種する
3. 胎児への治療として接種する
4. 生ワクチンであるため妊娠中は接種しない

**正答：4**

- 選択肢1：MRワクチンは弱毒生ワクチンである。不活化ワクチンという前提が誤っている。
- 選択肢2：妊娠後期だから接種できるという扱いではない。妊娠中は接種しない。
- 選択肢3：予防接種は胎児の感染を治療する目的のものではない。
- 選択肢4：麻疹・風疹の生ワクチンは妊娠中には接種しない。必要な場合は妊娠前や産後の接種について医療者に相談する。

## 第17問｜精神看護学：幻覚の理解

周囲に音源がない状況で、患者が「誰かが私を責める声が聞こえる」と訴えている。この体験を表す用語はどれか。

1. 見当識障害
2. 幻聴
3. 記憶障害
4. 観念奔逸

**正答：2**

- 選択肢1：見当識障害は、日時・場所・人物などの理解が障害されることをいう。音源のない声の体験とは区別する。
- 選択肢2：実際の音源がないのに声や音を聞く体験は幻聴である。この訴えだけで原因疾患を一つに断定しない。
- 選択肢3：記憶障害は覚えたり思い出したりする働きの障害であり、ここで述べられた体験とは異なる。
- 選択肢4：観念奔逸は考えが次々と移り変わる状態である。実際にはない声を聞くという知覚の体験とは異なる。

## 第18問｜精神看護学：希死念慮への対応

入院中の患者が「もう生きていたくない」と話した。最も適切な初期対応はどれか。

1. 「そんなことを考えてはいけない」と話を止める
2. 本人が望むので誰にも共有しないと約束する
3. 気持ちを受け止め、自傷の考えや切迫性を確認し、安全確保とチームでの対応につなぐ
4. 気分転換のため、一人で外出するよう勧める

**正答：3**

- 選択肢1：否定や説教で話を止めると、本人がつらさを伝えにくくなる。判断せずに聞く姿勢が必要である。
- 選択肢2：安全に関わる情報を秘密にすると約束しない。本人に説明し、支援に必要な範囲でチームと共有する。
- 選択肢3：率直に自傷の考えを確認すること自体が自殺を促すわけではない。切迫した危険があれば一人にせず、安全確保と速やかな支援につなぐ。
- 選択肢4：安全性が確認されないまま一人で外出させることは適切ではない。危険性を評価する。

## 第19問｜地域・在宅看護論：人生会議

療養中の本人が、以前に話し合った今後の医療・ケアの希望を変更したいと話した。人生会議（ACP）の考え方に沿う対応はどれか。

1. 一度記録した希望は変更できないと説明する
2. 今の思いを確認し、関係者と繰り返し話し合って記録を更新する
3. 本人の話を聞かず、家族だけで決定する
4. 希望を書面にすることを強制する

**正答：2**

- 選択肢1：価値観や希望は心身の状態や経験によって変化し得る。以前の記録だけで固定しない。
- 選択肢2：本人が大切にしていることを確認し、信頼する人や医療・ケアチームと繰り返し話し合う。内容を共有し、必要に応じて更新する。
- 選択肢3：家族の意見も大切だが、意思を表明できる本人を話し合いから外さない。
- 選択肢4：人生会議は本人の主体的な意思で行う。話し合いや書面作成を強制しない。

## 第20問｜看護の統合と実践：投与量の計算

計算上、薬液の濃度が20 mg/mLで、指示量が30 mgである。必要な薬液量はどれか。

1. 0.5 mL
2. 1.0 mL
3. 1.5 mL
4. 2.0 mL

**正答：3**

- 選択肢1：0.5 mLに含まれる量は20×0.5＝10 mgであり、指示量より少ない。
- 選択肢2：1.0 mLに含まれる量は20 mgであり、指示された30 mgに達しない。
- 選択肢3：必要量は指示量÷濃度で求める。30 mg÷20 mg/mL＝1.5 mLとなる。実際の投与では製剤・経路・指示なども確認する。
- 選択肢4：2.0 mLでは40 mgとなり、指示された30 mgを超える。
