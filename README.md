## 症状シミュレーター

`disease-simulator.js` で問題IDと発症演出を明示的に対応させています。2022〜2026年の全1,125問に病気の演出の有無を設定しています。病気・症状・治療後の状態を扱う問題では対応部位が赤く点滅し、その他の問題では患者との境界が揺らぐ投影演出を表示します。喘息、COPD、心不全、心房細動、狭心症などの病名・症状を表示し、対応部位や動きに反映します。選択肢や過去の病歴の単語だけでは発症させません。どちらの演出も同じミスの累計に含まれます。病気を割り当てない問題では、患者の輪郭が自分に重なります。

症状は次問でも残り、リセットで消去します。同じ病気の表示はまとめます。発症はゲーム上の設定であり、誤答が現実に病気を起こすという意味ではありません。症状文は公式問題の症例・正答選択肢・既存解説と、各設定のsourceに記載した公的・専門機関資料に基づきます。公式問題や解説データは変更しません。臨床的な数値・重症度の推定は行いません。

2026年の設定原本は `data/simulator-profiles.json` と `data/simulator-no-effect.json`。追加4年度の設定・除外理由は `data/additional-simulator-*.json`。局在を特定しない状態は全身を象徴的に点滅させ、臓器の病変を推定しません。`python scripts/build_disease_simulator.py` が全IDの重複・欠落を検出して表示用ファイルを生成します。集計は `data/simulator-coverage.json`。問題文・選択肢が変更された場合は旧演出を流用せず、対応の再確認が必要になります。

## 投影と勤務終了

患者の状況を自分に投影してしまう看護師、という設定で統一しています。`projection.js` と `projection.css` が境界の揺らぎ・二重の輪郭・投影の深まりを表示します。残りの力は全ミス共通で減少し、2割のミスで「自分に戻れなくなった」と勤務終了します。実際の心肺停止とは扱いません。最後の解説は終了前に読めます。正常終了は「自分のままで、夜勤終了」です。

上部はミス・終了までの回数・連続正解を表示します。疾患から推測したバイタル値は表示しません。解説や選択肢には揺れ・ぼかしを加えません。動きを減らす端末設定では輪郭の移動を止めます。
